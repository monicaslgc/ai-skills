# Knowledge Bases

This directory contains reusable domain knowledge that skills use to reason and perform work.

Knowledge is separate from:
- Skills: instructions for applying knowledge to a task.
- Kits: packages of related skills and shared workflow conventions.
- Project context: facts and decisions for a specific engagement.
- Tools: concrete deterministic or external operations.

All new and substantially revised knowledge must follow KNOWLEDGE_STANDARD.md.

Create a domain directory when there is enough coherent material to maintain. Choose document boundaries based on the subject, not a rigid file count. A compact, well-sourced knowledge base is better than a large collection of shallow files.

Each domain README should explain scope, consuming skills, document map, source policy, maintainer and review date.

Brand Strategy & Identity is the first migration pilot because it already has a multi-skill kit, shared naming methodology, quality gates and evaluation fixtures. Migrate incrementally without breaking the existing kit workflow.

See ../KNOWLEDGE_ARCHITECTURE.md and ../KNOWLEDGE_ROADMAP.md.
