# Brand Strategy & Identity Knowledge Base

## Scope
Reusable domain knowledge for brand strategy, research, naming, identity, verbal and visual expression, governance and measurement. This is domain knowledge, not a repository for individual client briefs or approvals.

## Consumers
The Brand Strategy & Identity kit. Skills consume only the sections relevant to their task and retain concise task-specific guidance in their own SKILL.md.

## Source and review policy
Use primary research, original framework publications, peer-reviewed research, official standards and established specialist literature where appropriate. Distinguish evidence from professional convention and repository recommendations. Do not reproduce copyrighted books or proprietary exercises.

- Maintainer: repository maintainer; assign a named reviewer for specialist sign-off.
- Last reviewed: 2026-11-19.
- Review trigger: changes to authoritative standards, core research, legal screening practice or dependent skill workflows.
- The source register records source type and known limitations. Verify current authoritative sources before compliance or legal use.

## Definition of done
A module is complete when it has substantive, sourced content; each consuming skill declares dependency and portability mode; duplicate guidance is reconciled; and behavioural tests demonstrate correct application. Fixture structure validation alone is not evidence of model behaviour.
