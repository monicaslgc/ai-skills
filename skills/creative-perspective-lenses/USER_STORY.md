# User story: Creative Perspective Lenses

As a person exploring a challenge, I want the AI to examine it through genuinely different thinking perspectives so that I can notice possibilities, meanings, mechanisms and tensions I may have missed.

## Scenario
A user is rethinking a local community event. They ask for a Creative Room round but do not want six versions of the same generic suggestion.

## Acceptance criteria
- Selects only relevant lenses, normally 2–4.
- Gives each lens a distinct contribution and question.
- Avoids presenting simulated lenses as real agents or people.
- Marks assumptions and speculation.
- Invites the user to redirect or combine ideas.

## Try it
"Use three different Creative Room lenses to rethink a neighbourhood event. Avoid generic event ideas."
