# User story: ha-automation-debugger

## Story

**As** a Home Assistant owner,
**I want** a clear explanation of why an automation misbehaved,
**so that** I fix the cause without trial and error.

## Scenario

My morning routine ran yesterday but not today.

## Acceptance criteria

- [ ] The automation's state and last run are checked.
- [ ] Trigger and condition evidence comes from history.
- [ ] Conflicts with other automations are checked.
- [ ] The cause is stated with evidence.
- [ ] Manual triggers only happen after confirmation.
