# De-slop designs

If the creator has a brand kit or style guide, it wins wherever it disagrees with this list. Ask for it before reviewing.

## Never ship these

- **Too dense:** at most 3 decorations plus the signature. The creator's art, the code or the look is the hero.
- **Default fonts** (DejaVu, Arial, Inter). Use the brand's headline face, a readable face for facts and a monospace face for codes. Check that every glyph renders (a decorative font may lack characters such as the multiplication sign; use "x").
- **No hierarchy.** Order: hero art, then headline or code, then rewards or details, then signature.
- **Glow, neon on dark, heavy drop shadows, glassmorphism, frosted panels, gradient orbs.**
- **Emoji as icons.** Use authentic game icons or nothing.
- **Everything in cards, side borders and pill buttons.** Prefer torn paper, mats and tape if that is the house style.
- **Inconsistent spacing.** One margin (for example 64 px on a 1080-wide canvas) and one gap.
- **Verbose text.** One line where one line works; no filler slogans.
- **Default palettes** (purple-indigo or muted amber "AI" colours). One palette per design, taken from the brand kit.
- **No organic texture.** If the brand is scrapbook or hand-made, build the texture from the creator's real components, not generated imagery.

## How to fix

1. Remove what carries no information, then name the exact fix (font, colour, icon). Never just "make it less AI".
2. Use the creator's approved designs as references and describe them concretely (for example scrapbook, cream mats, torn paper, chunky headline).
3. For a new important template, start from a layout or wireframe the creator approves.
4. Prefer real images over generated ones: screenshots, official art, the creator's photos.

## Check before delivering

- [ ] 3 decorations or fewer; nothing covers a face, the code or the rewards
- [ ] Only the brand fonts; every glyph renders
- [ ] One palette from the brand kit; no glow, gradient blobs or neon
- [ ] Readable on a phone at arm's length; consistent margins
- [ ] Only authentic game icons; no emoji as icons

## Safety

- Do not change the creator's approved artwork while cleaning up a design.
- Keep originals unchanged; deliver a new version.
