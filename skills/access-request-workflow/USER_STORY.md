# User story: access-request-workflow

## Story

**As** an IT or operations lead managing access,
**I want** workflows for joiners, movers, leavers and access requests,
**so that** people get the right access quickly and it is removed when no longer needed.

## Scenario

A colleague who left months ago still has active accounts.

## Acceptance criteria

- [ ] Standard role bundles and an approval matrix exist.
- [ ] Joiner, mover and leaver steps are defined.
- [ ] Reviews and an audit trail are included.
- [ ] Temporary access has an expiry.
- [ ] No secrets are recorded.
