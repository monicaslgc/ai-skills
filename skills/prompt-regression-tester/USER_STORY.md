# User story: prompt-regression-tester

## Audience
A practitioner who needs to compare prompt/model versions against a stable evaluation set..

## Scenario
The user supplies incomplete context and wants a repeatable, evidence-led result.

## Acceptance criteria
- Scope and source evidence are identified.
- Facts, assumptions and unknowns are distinguishable.
- Edge cases and validation checks are explicit.
- No unsupported facts are invented.
- Consequential actions remain behind human approval.

## Try it
> Compare prompt/model versions against a stable evaluation set. Use fictional or approved data, include an edge case, and explain how to validate the result.
