# User story: cv-screening-rubric

## Story

**As** a recruiter or manager with many applications,
**I want** CVs screened consistently against job-related criteria,
**so that** shortlists are fair, explainable and based on evidence.

## Scenario

Sixty applications arrived for a single role.

## Acceptance criteria

- [ ] Must-have and nice-to-have criteria are defined first.
- [ ] Each CV is scored with evidence notes.
- [ ] Protected characteristics are not used.
- [ ] Decisions are explained in neutral language.
- [ ] A person makes the final decision.
