# User story: continuous-improvement-experiment-designer

## Audience
An operations lead or practitioner who needs to design a practical improvement experiment that tests a specific operational hypothesis before wider rollout.

## Scenario
The user provides incomplete operational context and needs a repeatable, evidence-led artefact that can be reviewed before use.

## Acceptance criteria
- Hypothesis is falsifiable.
- Outcome and counter-metric are both defined.
- Success thresholds are labelled as supplied or proposed.
- Pilot has an approval gate and stop condition.
- Consequential changes remain subject to human approval.

## Try it
> Design a practical improvement experiment that tests a specific operational hypothesis before wider rollout. Use fictional or approved data, include an edge case, and explain how to validate the result.
