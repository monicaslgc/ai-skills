# User story: guide-freshness-check

## Story

**As** the owner of a help centre,
**I want** to know which guides no longer match the app,
**so that** users are not misled and support does not repeat answers.

## Scenario

A release moved two menus and renamed a button. Support tickets start quoting guides whose screenshots no longer match.

## Acceptance criteria

- [ ] Every guide is listed with owner, version verified and date.
- [ ] Each guide is classified as current, outdated, incomplete, unclear or obsolete after comparing every step.
- [ ] Missing guides for frequent tasks are listed.
- [ ] Problems name the exact step, the evidence and the fix.
- [ ] Priority, owner and due date are set, with a review cadence.
