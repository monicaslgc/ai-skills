# User story: brand-workflow-orchestrator

## Story
As a project owner, I want specialist skills sequenced with explicit gates so that work progresses without skipping evidence or approval.

## Scenario
A rebrand needs discovery, strategy, naming, identity and launch work.

## Acceptance criteria
- [ ] Stages/dependencies mapped
- [ ] only necessary skills routed
- [ ] approvals gate dependent stages
- [ ] state/version preserved
- [ ] changed upstream decisions trigger impact review
- [ ] no external action without consent.

## Try it
> Orchestrate a full rebrand with an unapproved positioning. Then change the approved audience and identify downstream work to revisit.
