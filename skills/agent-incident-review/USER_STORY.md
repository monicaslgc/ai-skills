# User story: agent-incident-review

## Story

**As** the owner of an AI agent that did something unexpected,
**I want** a structured, blameless review that ends in specific fixes,
**so that** the same failure does not happen again and others can trust the agent.

## Scenario

My assistant sent a draft to the wrong contact because it matched a similar name.

## Acceptance criteria

- [ ] Containment and evidence preservation come first.
- [ ] A timeline is built from logs.
- [ ] Root causes are categorised and supported by evidence.
- [ ] Actions have owners and dates, including a new regression test.
- [ ] The review is blameless.
