# User story: brand-naming-validation

## Story
As a founder, I want a documented risk screen for shortlisted names so that I know what must be checked before commitment.

## Scenario
Three candidate names are being considered for a SaaS product in Portugal and Spain.

## Acceptance criteria
- [ ] Jurisdictions/classes and search dates recorded
- [ ] language/meaning and confusion checked
- [ ] domain/handle results qualified
- [ ] trademark results treated as preliminary
- [ ] legal review recommended.

## Try it
> Screen three fictional names for PT and ES. Then provide a similar mark in one class and ask whether the name is legally safe.
