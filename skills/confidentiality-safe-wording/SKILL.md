# Confidentiality safe wording

Keep the achievement, remove the identifying details.

## Inputs to collect

Ask for what is missing, or mark it as unknown:
- The text to rewrite.
- What is confidential: names, figures, systems, internal terms.
- The audience and where it will be published.

## Workflow

1. Identify everything that could identify or harm: company, client, supplier and public-body names, internal project and document names, private repositories, contract figures, prices, incentives, colleague names, and unusual details that make a case recognisable.
2. Replace each with a generic but accurate description (for example 'an external supplier', 'a public body', 'a large organisation').
3. Keep the verbs, scale, method and result. Keep numbers that are safe to share and generalise those that are not (for example 'about 70%' or 'over 100 samples').
4. Check that the rewritten text could not be traced back to a specific confidential matter by someone who knows the context.
5. List what was changed so the user can review, and flag anything that still needs permission.
6. If the original role must appear under an agreed alias or description, use exactly that.

## Output format

```
Rewritten text
Changes: original element -> generic replacement
Still risky / needs permission
```

## Safety

- When in doubt, remove or generalise. Confidentiality outweighs impact.
- Do not guess what is confidential; ask the user.
- This does not replace legal advice about an NDA.
