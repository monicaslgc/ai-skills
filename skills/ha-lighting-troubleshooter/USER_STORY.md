# User story: ha-lighting-troubleshooter

## Story

**As** a Home Assistant owner with unreliable lights,
**I want** a step-by-step diagnosis that points to the likely cause,
**so that** I fix the real problem instead of replacing bulbs.

## Scenario

The living room lights ignore commands for a few minutes every evening.

## Acceptance criteria

- [ ] State and history are checked before conclusions.
- [ ] Automations that control the lights are reviewed.
- [ ] Patterns across devices point to hub or network causes.
- [ ] Changes are tested one at a time with confirmation.
- [ ] Fixes start with the smallest option.
