# User story: ha-entity-naming-audit

## Story

**As** a Home Assistant owner with a messy setup,
**I want** a consistent naming scheme with a safe rename plan,
**so that** my system is readable and renaming does not break routines.

## Scenario

I have dozens of entities named `light_3` and `switch_new`.

## Acceptance criteria

- [ ] Problems are found and grouped.
- [ ] A naming convention is proposed.
- [ ] A mapping table is produced.
- [ ] Dependencies are checked and a safe order is given.
- [ ] The skill does not rename anything itself.
