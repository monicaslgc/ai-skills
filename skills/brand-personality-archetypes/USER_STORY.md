# User story: brand-personality-archetypes

## Story
As a brand strategist, I want personality traits translated into observable behaviour so that the organisation can express a coherent character.

## Scenario
Stakeholders describe the brand as bold, caring, premium and playful.

## Acceptance criteria
- [ ] 3–5 traits and counter-traits defined
- [ ] observable examples supplied
- [ ] contradictions resolved by priority/context
- [ ] archetypes optional
- [ ] no psychometric claims.

## Try it
> Turn four vague adjectives into behaviour and voice rules. Then add conflicting 'formal and irreverent' traits without context.
