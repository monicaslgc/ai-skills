# User story: manage-automations

## Story

**As** a smart-home owner,
**I want** to list, inspect, create, enable, disable and trigger my home automations by asking,
**so that** I can change how my home behaves without editing configuration files.

## Scenario

A routine keeps turning the porch light on too early. I ask to see the automation, then to move it to sunset.

## Acceptance criteria

- [ ] The assistant shows the automation's current trigger, conditions and actions in readable form.
- [ ] Changes are explained before they are applied.
- [ ] It confirms the final state and how to undo the change.
- [ ] It never deletes an automation without explicit approval.
