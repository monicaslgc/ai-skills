# User story: naming-studio

## Story
As a founder, I want creative naming territories and a reasoned shortlist so that naming exploration is broad but strategic without investing in candidates that fail mandatory availability constraints.

## Scenario
A new platform needs a name that works across several languages. Both .pt and .com are mandatory.

## Acceptance criteria
- [ ] Naming brief constraints captured
- [ ] Multiple semantic territories explored in a raw candidate batch
- [ ] No long concepts or taglines before the availability gate
- [ ] Immediate handoff to brand-name-availability
- [ ] Detailed concepts limited to candidates passing the availability gate or explicitly accepted for review
- [ ] Linguistic risks flagged
- [ ] Validation kept separate
- [ ] No availability claims.

## Try it
> Generate a raw batch of 20 candidates for a B2B platform requiring .pt and .com. Do not write detailed concepts yet; hand the batch to brand-name-availability first.
