# User story: self-hosted-ai-workflow-designer

## Story

**As** someone connecting self-hosted services with AI steps,
**I want** a workflow design with data contracts, retries, security controls and tests,
**so that** the automation is reliable and safe before I build it.

## Scenario

I want new emails summarised by a local model and filed in a notes app.

## Acceptance criteria

- [ ] The design lists triggers, steps, inputs and outputs.
- [ ] Data contracts define required and optional fields, using synthetic examples.
- [ ] Retries, failure handling, authentication and logging are specified.
- [ ] Steps that need human approval are marked.
- [ ] A test plan is included.
