# User story: process-discovery-interviewer

## Audience
A practitioner who needs to map a process before automation, including owners, triggers, exceptions, volumes and systems of record..

## Scenario
The user provides incomplete context and wants a repeatable result without unsupported assumptions.

## Acceptance criteria
- Scope and available evidence are identified.
- Facts, assumptions and unknowns are distinguishable.
- Output is actionable and covers edge cases.
- Validation checks are explicit.
- Consequential changes require human approval.

## Try it
> Map a process before automation, including owners, triggers, exceptions, volumes and systems of record. Use a small fictional example. State assumptions, include an edge case and explain how to verify the result.
