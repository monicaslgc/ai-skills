# User story: interview-kit-builder

## Story

**As** a hiring manager preparing interviews,
**I want** a structured interview kit with a scoring rubric,
**so that** candidates are assessed fairly and consistently.

## Scenario

We are hiring a support analyst and each interviewer asks different questions.

## Acceptance criteria

- [ ] Competencies are defined for the role.
- [ ] Each has behavioural and situational questions with probes.
- [ ] A rubric describes strong, acceptable and weak answers.
- [ ] Interviewers score before discussing.
- [ ] Inappropriate questions are avoided.
