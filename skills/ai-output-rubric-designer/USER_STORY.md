# User story: ai-output-rubric-designer

## Audience
A practitioner who needs to create behaviourally anchored rubrics for correctness, grounding, completeness, safety and format..

## Scenario
The user supplies incomplete context and wants a repeatable, evidence-led result.

## Acceptance criteria
- Scope and source evidence are identified.
- Facts, assumptions and unknowns are distinguishable.
- Edge cases and validation checks are explicit.
- No unsupported facts are invented.
- Consequential actions remain behind human approval.

## Try it
> Create behaviourally anchored rubrics for correctness, grounding, completeness, safety and format. Use fictional or approved data, include an edge case, and explain how to validate the result.
