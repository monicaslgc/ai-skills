# User story: logo-design-brief

## Story
As a brand owner, I want a complete design brief so that designers can explore a logo within strategic and production constraints.

## Scenario
An approved strategy is ready for identity exploration.

## Acceptance criteria
- [ ] Approved strategy status checked
- [ ] use cases and constraints listed
- [ ] deliverables/licensing/handover specified
- [ ] acceptance criteria usable
- [ ] concept not prescribed
- [ ] legal checks flagged.

## Try it
> Write a logo brief for a multi-market SaaS product. Then ask for final logo direction while positioning remains unapproved.
