# User story: Productive Tension Mapper

As someone developing an idea, I want the AI to map the tension between competing directions so that disagreement reveals new design options instead of ending in a forced compromise.

## Scenario
A workshop concept needs to feel both spontaneous and carefully curated. The user wants to explore the tension before deciding.

## Acceptance criteria
- States both sides fairly.
- Identifies the values or assumptions underneath.
- Tests whether the conflict is real or a false binary.
- Suggests multiple ways to work with the tension.
- Leaves unresolved decisions with the user.

## Try it
"Map the tension between making this experience effortless and making it meaningful. Don't pick a side."
