# User story: brand-messaging-framework

## Story
**As** a product or marketing lead, **I want** a clear message hierarchy for priority audiences, **so that** teams communicate a consistent value proposition while adapting proof and emphasis to each channel.

## Scenario
A growing company has inconsistent sales and marketing messages and needs a shared framework before producing new campaign copy.

## Acceptance criteria
- [ ] The framework references an approved or explicitly provisional positioning.
- [ ] It defines the core promise, supporting pillars, audience messages and objections.
- [ ] Every factual claim has a proof point or is marked as needing substantiation.
- [ ] Stable strategic messages are distinguished from channel adaptations.
- [ ] Messages address specific audience needs and meaningful differentiation.
- [ ] The output includes a usable audience/message/proof/CTA matrix.
- [ ] Validation limitations and next research steps are explicit.
