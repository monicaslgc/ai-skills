# User story: ai-failure-analyzer

## Audience
A practitioner who needs to classify failed ai outputs into evidence-backed causes and regression tests..

## Scenario
The user supplies incomplete context and wants a repeatable, evidence-led result.

## Acceptance criteria
- Scope and source evidence are identified.
- Facts, assumptions and unknowns are distinguishable.
- Edge cases and validation checks are explicit.
- No unsupported facts are invented.
- Consequential actions remain behind human approval.

## Try it
> Classify failed AI outputs into evidence-backed causes and regression tests. Use fictional or approved data, include an edge case, and explain how to validate the result.
