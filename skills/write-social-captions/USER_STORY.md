# User story: write-social-captions

## Story

**As** a gaming creator posting to several platforms,
**I want** paste-ready captions, titles, descriptions and hashtags for each platform,
**so that** my posts sound like me, stay accurate, and are not the same text pasted everywhere.

## Scenario

I have one finished clip and need copy for TikTok, Reels, Shorts and a YouTube description.

## Acceptance criteria

- [ ] Each platform gets its own copy, not identical text with a label.
- [ ] Names, rarities, versions and release facts are verified or not stated.
- [ ] Hashtags are few, accurate, and never invented volumes or reach.
- [ ] Results, spending and attempt counts are never made up.
- [ ] Output is paste-ready text without a long explanation.
