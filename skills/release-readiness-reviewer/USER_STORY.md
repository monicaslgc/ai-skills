# User story: release-readiness-reviewer

## Audience
A practitioner who needs to review product, support, data, security, analytics, rollout and rollback readiness..

## Scenario
The user provides incomplete context and wants a repeatable result without unsupported assumptions.

## Acceptance criteria
- Scope and available evidence are identified.
- Facts, assumptions and unknowns are distinguishable.
- Output is actionable and covers edge cases.
- Validation checks are explicit.
- Consequential changes require human approval.

## Try it
> Review product, support, data, security, analytics, rollout and rollback readiness. Use a small fictional example. State assumptions, include an edge case and explain how to verify the result.
