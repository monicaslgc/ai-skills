# User story: Creative Convergence

As someone who has explored several possible directions, I want the AI to reveal patterns and useful combinations without flattening everything into one idea so that I can see what is worth developing next.

## Scenario
A user has explored twelve possible ways to make a community workshop more welcoming. Some ideas overlap, while two unusual ideas address a different need.

## Acceptance criteria
- Identifies meaningful patterns and keeps distinct directions separate.
- Suggests combinations only when the elements complement each other.
- Preserves unusual ideas and conflicting values.
- Does not rank or score unless requested.
- Makes it easy for the user to choose what happens next.

## Try it
"Here are ten rough ideas. Find the patterns and possible combinations, but don't rank them or discard the outliers."
