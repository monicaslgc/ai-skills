# User story: photo-post-deliverables

## Story

**As** a creator posting photo sets and carousels,
**I want** every image exported in the five common sizes with sensible crops,
**so that** I can post to several platforms without resizing by hand.

## Scenario

I have eight outfit photos and need versions for vertical, portrait and square posts.

## Acceptance criteria

- [ ] Five sizes are produced for each image with matching filenames.
- [ ] Cropped sizes keep any headpiece intact, the face in the upper third, and props in frame.
- [ ] Horizontal photos for 9x16 are cropped, not shrunk into a blurred frame.
- [ ] Original images are not overwritten.
- [ ] A caption file is created in the project folder.
