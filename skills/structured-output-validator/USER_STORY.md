# User story: structured-output-validator

## Audience
A practitioner who needs to validate generated json/structured data against schemas and business rules..

## Scenario
The user supplies incomplete context and wants a repeatable, evidence-led result.

## Acceptance criteria
- Scope and source evidence are identified.
- Facts, assumptions and unknowns are distinguishable.
- Edge cases and validation checks are explicit.
- No unsupported facts are invented.
- Consequential actions remain behind human approval.

## Try it
> Validate generated JSON/structured data against schemas and business rules. Use fictional or approved data, include an edge case, and explain how to validate the result.
