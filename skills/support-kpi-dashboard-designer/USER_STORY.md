# User story: support-kpi-dashboard-designer

## Story

**As** a support lead building reports,
**I want** clear metric definitions and a dashboard people can use,
**so that** we measure the right things and everyone reads them the same way.

## Scenario

Two managers quote different resolution times from the same system.

## Acceptance criteria

- [ ] Each metric has a precise definition and source.
- [ ] Views fit each audience.
- [ ] Distributions and sample sizes are shown.
- [ ] Targets are labelled proposed or agreed.
- [ ] Warnings about misuse are included.
