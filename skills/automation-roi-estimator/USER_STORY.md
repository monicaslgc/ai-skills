# User story: automation-roi-estimator

## Audience
A practitioner who needs to estimate automation value with transparent assumptions, costs, exception rates and sensitivity ranges..

## Scenario
The user provides incomplete context and wants a repeatable result without unsupported assumptions.

## Acceptance criteria
- Scope and available evidence are identified.
- Facts, assumptions and unknowns are distinguishable.
- Output is actionable and covers edge cases.
- Validation checks are explicit.
- Consequential changes require human approval.

## Try it
> Estimate automation value with transparent assumptions, costs, exception rates and sensitivity ranges. Use a small fictional example. State assumptions, include an edge case and explain how to verify the result.
