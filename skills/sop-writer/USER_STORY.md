# User story: sop-writer

## Story

**As** someone who owns a recurring task,
**I want** a clear SOP anyone can follow,
**so that** work is done consistently and does not depend on one person.

## Scenario

Only one colleague knows how to run the monthly reconciliation.

## Acceptance criteria

- [ ] Purpose, scope and roles are stated.
- [ ] Steps start with a verb and have checks.
- [ ] Exceptions and escalation are included.
- [ ] Version and owner are recorded.
- [ ] A newcomer can follow it successfully.
