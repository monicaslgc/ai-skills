# User story: memory-recall

## Story

**As** someone who works on long-running projects across many sessions,
**I want** my assistant to load relevant past context before it starts a task,
**so that** I do not have to re-explain my setup and earlier decisions every time.

## Scenario

I start a new session about a project I touched last month. The assistant checks memory first and tells me what it found.

## Acceptance criteria

- [ ] The assistant recalls context before starting when past work is likely to matter.
- [ ] It reports briefly what it found and how it will use it.
- [ ] It does not dump raw transcripts.
- [ ] It continues normally when nothing relevant exists.
