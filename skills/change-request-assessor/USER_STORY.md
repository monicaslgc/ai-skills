# User story: change-request-assessor

## Story

**As** a project manager receiving late requests,
**I want** a clear impact assessment with options,
**so that** stakeholders decide with the trade-offs in front of them and the baseline stays honest.

## Scenario

A sponsor asks to add a reporting feature three weeks before launch.

## Acceptance criteria

- [ ] Impact is shown for scope, schedule, cost, quality and risk.
- [ ] Estimates have ranges and a basis.
- [ ] At least two options are offered, with a recommendation.
- [ ] Approvers and baseline updates are named.
- [ ] The change is not assumed to be approved.
