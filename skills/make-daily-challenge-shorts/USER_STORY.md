# User story: make-daily-challenge-shorts

## Story

**As** a creator taking part in a month-long daily challenge,
**I want** each day's Short produced from my own template and prompt list,
**so that** every day looks consistent and I do not rebuild the format from scratch.

## Scenario

It is day 5 of the challenge and I have my raw clips and template ready.

## Acceptance criteria

- [ ] The creator's template and corrections file are read first and win over defaults.
- [ ] Clip lengths, intro, day circle and final showcase follow the template.
- [ ] The day number appears without a leading zero.
- [ ] A timeline file for the editor is delivered with each render.
- [ ] The share code is never altered, and nothing is posted automatically.
