# Make daily challenge Shorts

A themed daily challenge produces one Short per day from the same template. Consistency matters more than novelty.

## Before starting

1. Ask for the creator's template or reference timeline (their editor project or a finished Day 1) and for their running corrections file, if they keep one. Read the corrections first; it wins over this skill when they differ.
2. Ask for the challenge's prompt list and dates. The supplied list is the authority; do not call the challenge official without evidence.

## Format rules (confirm each against the creator's template)

- Shorts only. Never make a long version of a day.
- Follow the template's clip lengths and total duration exactly. Dissolves sit inside the clips and must not shorten the video.
- Footage stays fully blurred under the intro for the template's intro length, then turns sharp, like the creator's finished Day 1.
- Day-number circle: the number without a leading zero ("2", not "02"), centred on the circle.
- The last clip is the spinning showcase. If the day's raw folder has a video with spin or showcase in the name, use it. In the spin, the character is centred, whole body visible, with game UI, menus and screen text cropped out.
- A handwriting font can make letters look like digits. Never change the creator's share code to "fix" it.

## Files

- The creator's own export always wins over an agent render.
- Every render comes with a timeline file for their editor in the day's project folder.
- Work is saved only in the creator's chosen storage. Treat photo-library source albums as read-only.

## Copy

Use `write-social-captions` with the challenge's hashtag set (supplied by the creator). Never say "first" unless the day is 1. No "full breakdown in the video". Describe the look, the prompt and the game, never the making of the video.

## Before reporting done

Inspect the exported file at the start (blurred intro), at the change to sharp, at the day circle and at the final spin. Confirm the timeline file exists. Draft only: never post or schedule unless the task says so.
