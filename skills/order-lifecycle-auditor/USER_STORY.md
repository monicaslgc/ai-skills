# User story: order-lifecycle-auditor

## Audience
A practitioner who needs to trace order-state transitions and identify stuck, contradictory or impossible lifecycle states..

## Scenario
The user supplies incomplete context and wants a repeatable, evidence-led result.

## Acceptance criteria
- Scope and source evidence are identified.
- Facts, assumptions and unknowns are distinguishable.
- Edge cases and validation checks are explicit.
- No unsupported facts are invented.
- Consequential actions remain behind human approval.

## Try it
> Trace order-state transitions and identify stuck, contradictory or impossible lifecycle states. Use fictional or approved data, include an edge case, and explain how to validate the result.
