# User story: prioritization-scorecard

## Audience
A practitioner who needs to compare opportunities with explicit criteria, adjustable weights and visible trade-offs..

## Scenario
The user provides incomplete context and wants a repeatable result without unsupported assumptions.

## Acceptance criteria
- Scope and available evidence are identified.
- Facts, assumptions and unknowns are distinguishable.
- Output is actionable and covers edge cases.
- Validation checks are explicit.
- Consequential changes require human approval.

## Try it
> Compare opportunities with explicit criteria, adjustable weights and visible trade-offs. Use a small fictional example. State assumptions, include an edge case and explain how to verify the result.
