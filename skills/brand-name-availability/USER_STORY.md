# User story: brand-name-availability

## Story
As a founder, I want candidate names screened against mandatory domains and obvious company/trademark conflicts before concept development so that we do not waste time developing names we cannot realistically use.

## Scenario
A team has generated 25 candidate names for a brand intended for Portugal and international markets. Both .pt and .com are mandatory.

## Acceptance criteria
- [ ] All candidates are screened in one batch.
- [ ] .pt and .com are checked independently using authoritative or reputable live sources.
- [ ] Registered, reserved, restricted or inconclusive mandatory domains stop detailed development.
- [ ] Relevant company registers and trademark databases are searched.
- [ ] Exact and similar conflicts are distinguished.
- [ ] Each result includes source, direct URL, date/time and confidence.
- [ ] Only candidates passing mandatory checks move to detailed concept development.
- [ ] No legal-clearance or guaranteed-availability claims are made.
