# User story: operational-controls-checklist-builder

## Audience
An operations lead or practitioner who needs to translate a repeatable operational task into a checklist that prevents omissions and makes exceptions auditable.

## Scenario
The user provides incomplete operational context and needs a repeatable, evidence-led artefact that can be reviewed before use.

## Acceptance criteria
- Each item is observable and can be evidenced.
- Mandatory requirements cite supplied policy or are marked unknown.
- Exceptions have a defined next step.
- Normal and failure cases have been tested.
- Consequential changes remain subject to human approval.

## Try it
> Translate a repeatable operational task into a checklist that prevents omissions and makes exceptions auditable. Use fictional or approved data, include an edge case, and explain how to validate the result.
