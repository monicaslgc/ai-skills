# User story: style-inspired-cosplay-looks

## Story

**As** a creator showing dress-up game outfits inspired by other characters,
**I want** an accurate breakdown of the cues I reproduced and how to describe them,
**so that** my posts are honest about what is inspired versus official.

## Scenario

I styled an outfit as a character from another game and want a description and hook for the post.

## Acceptance criteria

- [ ] The actual outfit is inspected before any description is written.
- [ ] Cues from the source character are mapped only to what was really reproduced.
- [ ] The look is called 'inspired' or 'reimagined' when not literal.
- [ ] No official crossover or inventory claim is made.
- [ ] Copy is handed off to the caption skill.
