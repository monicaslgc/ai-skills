# Style inspired cosplay looks

Use when a dress-up game character is styled as, inspired by, or reimagining another character.

## Method

1. Inspect the actual outfit first. Record colour distribution, silhouette, hair, accessories, textures and pose.
2. Inspect the named character's official appearance where reachable. Pick three to five high-recognition cues and the mood or role. No lore guesses.
3. Map each cue to what was actually reproduced (a strong red and black palette may transfer while armour or a unique prop does not).
4. Call it "inspired" or "reimagined" when it is not literal. Never apologise for the game's wardrobe limits or imply the look failed for not being exact.
5. Refinements: name only pieces whose identity and availability you verified. Otherwise suggest categories (shorter jacket, gold accessory, stronger red accent).
6. Preserve the existing look. A caption request is not permission to generate a replacement outfit.
7. Pick a hook that suits the character: recognition, personality, contrast, transformation or a specific detail. Vary the pattern between posts.
8. Build a reveal sequence only when asked: readable full silhouette, two or three signature details, hero pose. Use real clips, never invented captures.

## Copy distinctions

- A dress-up game character styled as a character from another game: both games belong in the context and possibly the tags.
- Gameplay of the other game with no dress-up character: no dress-up game tags.
- A concept such as "character ready to fight the villain" is an interpretation, not an official alternate costume.
- A look inspired by a banner's top-rarity and lower-rarity designs: never claim both sets were equipped. Inspiration and inventory are different.
- A look made before a collaboration differs from a showcase of the collaboration's real outfit. Check which is on screen.
- "Appreciation before release" keeps its original time context or is rewritten for the real posting date.

Any characters or games named in earlier requests are examples only, not a roster or confirmed current releases. Refresh facts before using them.
