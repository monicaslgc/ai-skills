# User story: project-plan-builder

## Story

**As** a project manager planning a three-month delivery,
**I want** a plan with ranges, dependencies and a clear critical path,
**so that** I can tell the sponsor honestly whether the deadline is realistic.

## Scenario

The sponsor wants a launch in twelve weeks and my team has two people part-time.

## Acceptance criteria

- [ ] Every work package has an owner, an estimate range and its dependencies.
- [ ] The critical path and buffer are shown.
- [ ] Team capacity is compared with the load.
- [ ] If the date does not fit, options are listed.
- [ ] Guessed estimates are labelled as guesses.
