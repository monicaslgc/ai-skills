# User story: memory-search

## Story

**As** someone who keeps notes and conversations in a personal memory store,
**I want** to search past conversations and notes by topic,
**so that** I can find a decision, command or explanation I already worked out.

## Scenario

I remember solving a backup problem months ago but not how. I ask the assistant to find it.

## Acceptance criteria

- [ ] The assistant searches with specific terms and refines if the first results are vague.
- [ ] It summarises each match with title, date and key points.
- [ ] It opens the full conversation only when asked.
- [ ] It says plainly when nothing relevant is found.
