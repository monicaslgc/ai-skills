# User story: ha-automation-designer

## Story

**As** a Home Assistant owner,
**I want** a well-designed automation with YAML I can review,
**so that** my routines work reliably and do not conflict.

## Scenario

I want the hallway light to come on at night when I walk through, but not when I am away.

## Acceptance criteria

- [ ] Existing automations are checked first.
- [ ] Real entity IDs are confirmed.
- [ ] Triggers, conditions, mode and failure handling are specified.
- [ ] YAML and a test plan are provided.
- [ ] The user installs and reviews it; nothing is installed automatically.

## Try it

> Design an automation that turns on the hallway light at night when motion is detected, but only when someone is home.
