# User story: local-ai-deployment-planner

## Story

**As** someone who wants to run AI models on my own hardware,
**I want** a clear plan covering capacity, architecture, risks and validation,
**so that** I choose a setup that actually fits my machine before I spend time or money.

## Scenario

I have a 16 GB graphics card and want a chat model plus speech-to-text running together.

## Acceptance criteria

- [ ] Assumptions and unknowns are listed explicitly.
- [ ] A capacity check compares memory and compute needs with the hardware.
- [ ] The proposed architecture, risks and a validation plan are included.
- [ ] No cloud service is assumed unless I ask for one.
