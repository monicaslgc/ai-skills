# Design YouTube thumbnails

## Authenticity and likeness (applies to all visuals)

- Preserve the creator's selected photo and face. The current image is authoritative over remembered details. Do not reshape features, invent another face or fabricate accessories.
- Real game art stays real: screenshots, outfits and character art are not redrawn. Keep logos and lettering. Never invent a garment, rare result, stat or item count.
- "Less AI" means fewer artifacts, correct anatomy, real source material, clean masks and fewer effects. It does not mean paper texture over a flawed composition.
- Use the exact channel name spelling. No universal palette or font is approved; extract them from approved artwork. Game art uses that game's colours. Past project palettes are project choices, not channel rules.

## Intake

Inventory every asset by filename or attachment index: creator photo, game art, example thumbnail, logo, meme source, exact text, latest approved variant. The most recent selected photo is mandatory when the creator switches. If asked to remove the creator, remove them entirely plus any placeholder, rebalance, and do not silently add a mascot.

## Workflow

1. State the honest video promise in one sentence (pulling and testing, low-spender build, piece showcase, tutorial, reaction).
2. Choose the real visual payoff from authorised footage or art.
3. One clear focal subject, a supporting reaction if asked, readable text. Hierarchy before decoration.
4. Match the reference's type traits (weight, outline, shadow, line spacing, emphasis), not its artifacts.
5. Use real source pixels for compositing. Do not repaint game art, resculpt the face or generate new accessories.
6. Edit expressions only when explicitly asked, tightly constrained, with identity compared. A real source crop often beats a generated smile. Do not bring back a removed hand.
7. Use a short title when the wording is open. If exact longer wording is required, keep it with deliberate hierarchy or offer a clearly labelled shorter alternative; never quietly change it.
8. Add decorations only if they support the story. No excess glow, glitter, outlines, fake depth or plastic skin.
9. Check a phone-size preview and a full-resolution crop, then export.

Deliver: final thumbnail, editable project, linked assets, one small preview. Two variants must differ in a real design choice. Keep the approved version and label variants. Use landscape 16:9 (1280x720 or 1920x1080 working sizes), and check current upload limits when relevant.

## Revision rules

- "Don't edit me so much": reduce alteration, restore the chosen photo, keep natural texture.
- "You didn't use the new photo": compare actual asset IDs and replace the correct layer.
- "Keep a real game image": use supplied game imagery, not an approximation.
- "Text looks AI": retypeset with real fonts, spacing and editable layers.
- "For mobile": preview small and resize text.

Make the smallest change that satisfies the request. "Improve" does not allow replacing the concept, photo, character or palette. Keep a change list: target version, requested change, protected elements, acceptance test.

## Editable templates

Use the editor's native import format; an SVG is not a substitute. Inspect a valid export from the current version of the editor first and reuse its real node types and property names; never fabricate fields. Name layers (background, source character, creator photo, headline, supporting text, accents, crop guides). Keep text as text and confirm fonts. Import into the editor when available and make a small edit to prove editability; a JSON parser only proves syntax. If no valid schema or editor is available, give a clearly labelled draft spec and ask for the minimum valid sample; do not call it import-ready. Make headline, game or version, character image, creator image, palette and badge the editable fields, and do not build a complex system for one layout.

## Acceptance gates

Correct source and version; correct ratio and size with no stretching; identity and game art kept; requested removals complete (tails, white boxes, shadows, text remnants); transparent means real alpha; spelling right and readable on a phone; no invented patterns; editability tested or stated as unverified; approved elements survived; the exported file itself inspected, not the editor canvas.

## Safety

- Use only photos, art and music the creator has the right to use.
- Do not claim results, spending or rewards that were not supplied.
- Do not upload, publish or send anything without explicit approval.
