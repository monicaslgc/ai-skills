# User story: design-youtube-thumbnails

## Story

**As** a YouTube creator,
**I want** thumbnails and editable templates that use my real photos and real game art,
**so that** they look authentic, read well on a phone, and I can revise them without starting over.

## Scenario

I switched to a new photo and want the latest thumbnail updated with less visible AI editing.

## Acceptance criteria

- [ ] The most recent selected photo is used and the layer is verified.
- [ ] Game art and the creator's face are not redrawn or reshaped.
- [ ] The text is readable at phone size and spelled correctly.
- [ ] Only the requested changes are made, with a change list.
- [ ] The final exported file is inspected, not just the editor canvas.
