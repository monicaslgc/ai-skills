# User story: job-posting-scorer

## Story

**As** a job seeker with a long list of postings,
**I want** each posting scored against my profile using rules I can read,
**so that** I focus on the roles that really fit and understand why the others do not.

## Scenario

I have collected 40 postings and want the best 5, with reasons.

## Acceptance criteria

- [ ] Scores use only the skills I listed and never invent new ones.
- [ ] Each score is broken down into role fit, matched and missing skills, and adjustments.
- [ ] Postings are grouped into strong, possible and weak bands.
- [ ] The assistant explains the top results in plain language.
- [ ] No application is sent without my approval.
