# User story: brand-application-designer

## Story
As a design lead, I want approved brand rules translated into touchpoint specifications so that teams can implement the identity consistently.

## Scenario
A new identity must be applied to a responsive website, social templates and sales deck.

## Acceptance criteria
- [ ] Touchpoints are inventoried
- [ ] approved assets are referenced
- [ ] responsive/accessibility states are specified
- [ ] constraints and acceptance criteria are testable
- [ ] missing rules are flagged.

## Try it
> Specify a responsive homepage and social template from a supplied identity. Then remove logo/colour rules and ask the skill to invent them.
