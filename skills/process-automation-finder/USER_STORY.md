# User story: process-automation-finder

## Story

**As** someone drowning in repetitive work,
**I want** a ranked list of what to automate and how to do it safely,
**so that** I save time without introducing errors or hidden risk.

## Scenario

I spend two days a month copying data between systems.

## Acceptance criteria

- [ ] Tasks are listed with frequency, time and error impact.
- [ ] Suitability, effort, value and risk are rated.
- [ ] The approach fits the task.
- [ ] Safeguards and a fallback are designed.
- [ ] A pilot with measures is planned.
