# User story: ai-eval-dataset-builder

## Audience
A practitioner who needs to build privacy-safe evaluation datasets with positive, negative and boundary cases..

## Scenario
The user supplies incomplete context and wants a repeatable, evidence-led result.

## Acceptance criteria
- Scope and source evidence are identified.
- Facts, assumptions and unknowns are distinguishable.
- Edge cases and validation checks are explicit.
- No unsupported facts are invented.
- Consequential actions remain behind human approval.

## Try it
> Build privacy-safe evaluation datasets with positive, negative and boundary cases. Use fictional or approved data, include an edge case, and explain how to validate the result.
