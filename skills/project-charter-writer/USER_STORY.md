# User story: project-charter-writer

## Story

**As** a project manager starting a new initiative,
**I want** a one-page charter that sets purpose, scope and success measures,
**so that** sponsors can approve it quickly and the team works from one shared definition.

## Scenario

A sponsor describes a system migration in two paragraphs. I need a charter to review in tomorrow's kickoff.

## Acceptance criteria

- [ ] The charter fits on one page with every section filled or marked open.
- [ ] Scope lists what is out, not only what is in.
- [ ] Each objective has a measure and a date.
- [ ] Assumptions are marked confirmed or unconfirmed.
- [ ] No budget, date or approval is invented.

## Try it

> Write a project charter for migrating our team's tickets to a new help desk by the end of Q2.
