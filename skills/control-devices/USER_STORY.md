# User story: control-devices

## Story

**As** a smart-home owner,
**I want** to control lights, climate, covers and fans by describing what I want in plain language,
**so that** I do not have to open an app or remember device names.

## Scenario

It is evening and I am on the sofa. I ask the assistant to dim the living room lights and set the thermostat a little lower.

## Acceptance criteria

- [ ] The assistant finds the right device, or lists the options when the name is ambiguous.
- [ ] It uses the correct service and values (for example brightness as a percentage).
- [ ] It confirms the result in plain language, not raw API output.
- [ ] It asks before switching off several devices at once.

## Try it

> Dim the living room to 30% and set the bedroom thermostat to 20 degrees.
