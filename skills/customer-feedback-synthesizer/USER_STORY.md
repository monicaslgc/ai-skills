# User story: customer-feedback-synthesizer

## Audience
A practitioner who needs to cluster feedback into evidence-backed themes, jobs, pain points and open questions..

## Scenario
The user provides incomplete context and wants a repeatable result without unsupported assumptions.

## Acceptance criteria
- Scope and available evidence are identified.
- Facts, assumptions and unknowns are distinguishable.
- Output is actionable and covers edge cases.
- Validation checks are explicit.
- Consequential changes require human approval.

## Try it
> Cluster feedback into evidence-backed themes, jobs, pain points and open questions. Use a small fictional example. State assumptions, include an edge case and explain how to verify the result.
