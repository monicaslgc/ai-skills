# User story: moodboard-art-direction

## Story
As a creative lead, I want strategic visual territories so that design exploration has rationale and boundaries.

## Scenario
The approved brand strategy needs visual exploration before identity design.

## Acceptance criteria
- [ ] Multiple territories are distinct
- [ ] references annotated
- [ ] source and rights status recorded
- [ ] strategic rationale explicit
- [ ] no copying
- [ ] draft status and approval gate clear.

## Try it
> Create two visual territories from approved traits. Then ask to reproduce a competitor's logo and campaign look.
