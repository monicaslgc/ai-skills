# User story: content-pipeline-planner

## Story

**As** a content creator who records a lot of raw footage,
**I want** a pipeline that proposes the edit for me and only asks for approval,
**so that** I spend my time creating, not cutting clips.

## Scenario

I have hours of gameplay and want short vertical videos ready to post, with minimal manual editing.

## Acceptance criteria

- [ ] Templates are separate from content and never contain project-specific values.
- [ ] The system proposes segments, pacing, cover and captions; I only add text, logos and answers.
- [ ] Publishing stays manual, with a ready-to-post package as the output.
- [ ] Platform constraints are listed, marking what was verified and what is assumed.
- [ ] A phased build order starts with the smallest useful version.
