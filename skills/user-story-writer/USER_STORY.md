# User story: user-story-writer

## Story

**As** someone who builds or shares tools, skills or automations,
**I want** a short user story with testable acceptance criteria written for each one,
**so that** other people can see who it is for, what it should do, and how to check that it works.

## Scenario

I have just finished a new skill and want to publish it. Before I do, I want a one-page description that a newcomer can read and a reviewer can test against.

## Acceptance criteria

- [ ] The story names a role and situation, not a real person.
- [ ] The want is an outcome, not a feature or an implementation detail.
- [ ] There is a short, concrete scenario using generic details.
- [ ] Three to six acceptance criteria are written, and each can be checked by someone who did not write the skill.
- [ ] If the skill can change anything, at least one criterion covers approval or safety.
- [ ] Missing or unclear information is marked as an open question, not guessed.
- [ ] No private data appears in the file.
