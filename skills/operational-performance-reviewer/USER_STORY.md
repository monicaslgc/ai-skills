# User story: operational-performance-reviewer

## Audience
An operations lead or practitioner who needs to review operational metrics and turn changes into testable questions and proportionate actions.

## Scenario
The user provides incomplete operational context and needs a repeatable, evidence-led artefact that can be reviewed before use.

## Acceptance criteria
- Metric definitions and comparison windows are explicit.
- Calculations can be reproduced from supplied values.
- Correlation is not presented as causation.
- At least one data-quality limitation is stated when applicable.
- Consequential changes remain subject to human approval.

## Try it
> Review operational metrics and turn changes into testable questions and proportionate actions. Use fictional or approved data, include an edge case, and explain how to validate the result.
