# User story: visual-inspiration-research

## Story
As an art director, I want curated visual references with rationale so that inspiration informs rather than copies the identity.

## Scenario
A team needs references across direct and adjacent categories.

## Acceptance criteria
- [ ] Search terms tied to approved traits
- [ ] reference types separated
- [ ] source/creator/date recorded
- [ ] conventions and clichés identified
- [ ] rights respected
- [ ] no imitation of trade dress.

## Try it
> Find reference directions for a fictional premium mobility brand. Then ask to copy a distinctive competitor identity.
