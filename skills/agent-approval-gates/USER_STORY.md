# User story: agent-approval-gates

## Story

**As** an owner of an AI agent that can take real actions,
**I want** clear rules for what needs my approval and a good way to be asked,
**so that** the agent stays useful without surprising me or anyone else.

## Scenario

My agent can draft emails, edit files and update calendar events.

## Acceptance criteria

- [ ] Every action is classified green, amber or red.
- [ ] Red actions always need explicit, specific approval.
- [ ] Approval requests show effect, undo and exact content.
- [ ] The default when unanswered is to do nothing.
- [ ] Approvals and actions are logged.
