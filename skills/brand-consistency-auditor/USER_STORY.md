# User story: brand-consistency-auditor

## Story
**As** a brand manager, **I want** specific assets checked against the current approved guidelines, **so that** I can identify and correct inconsistent execution without changing the rules during the audit.

## Scenario
A company has approved brand guidelines and wants to review a set of campaign assets, website pages and sales materials before publication.

## Acceptance criteria
- [ ] The current guideline version and review scope are identified.
- [ ] Each reviewed touchpoint is inventoried with channel, audience, market and asset version.
- [ ] Findings cite the exact rule and observed evidence.
- [ ] Objective violations are separated from subjective creative opportunities.
- [ ] Missing or ambiguous rules are flagged as governance gaps, not invented.
- [ ] Each issue includes severity, reach and a concrete correction.
- [ ] Proposed guideline changes are routed separately to the brand owner.

## Try it
> Review a fictional campaign pack against a supplied set of brand rules. If a rule is missing, mark the item not assessable rather than guessing.
