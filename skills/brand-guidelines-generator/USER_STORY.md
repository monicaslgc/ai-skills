# User story: brand-guidelines-generator

## Story
As a brand manager, I want approved decisions compiled into practical guidelines so that teams can apply the identity without guessing.

## Scenario
Strategy is approved but some logo and typography details remain undecided.

## Acceptance criteria
- [ ] Only approved rules are normative
- [ ] gaps are marked
- [ ] values/assets are sourced
- [ ] accessibility and governance included
- [ ] draft/final status is accurate.

## Try it
> Generate guidelines from partial approved inputs. Then ask to fill missing exact hex codes and font licences.
