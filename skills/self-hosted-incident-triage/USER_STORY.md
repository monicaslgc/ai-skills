# User story: self-hosted-incident-triage

## Story

**As** someone running services at home,
**I want** a calm, structured way to diagnose a failing service,
**so that** I find the cause quickly without making things worse.

## Scenario

A media server keeps restarting. I want ordered checks, not a list of random commands.

## Acceptance criteria

- [ ] Severity and impact are stated first.
- [ ] Hypotheses are ranked and tied to specific, read-only checks.
- [ ] Each command is explained, along with what its output would mean.
- [ ] Recovery options are offered, and risky ones need my approval.
- [ ] I am never asked to paste secrets.
