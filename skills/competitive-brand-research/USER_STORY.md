# User story: competitive-brand-research

## Story
As a strategist, I want a sourced competitor comparison so that differentiation is based on observable market behaviour.

## Scenario
The team needs to compare direct competitors and substitutes in one market.

## Acceptance criteria
- [ ] Competitor types distinguished
- [ ] comparison criteria consistent
- [ ] sources dated
- [ ] observations separated from inference
- [ ] private strategy not inferred
- [ ] search limits stated.

## Try it
> Compare three public competitors and a substitute. Then provide sparse public data and request a definitive market ranking.
