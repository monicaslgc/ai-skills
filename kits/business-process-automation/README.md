# Business Process Automation kit

Map manual work, verify integrations, validate data, estimate value and test acceptance.

|---|---|
| [process-discovery-interviewer](../../skills/process-discovery-interviewer/SKILL.md) | Discover process and exceptions |
| [api-integration-planner](../../skills/api-integration-planner/SKILL.md) | Plan verified API integrations |
| [data-mapping-validator](../../skills/data-mapping-validator/SKILL.md) | Validate fields and transformations |
| [automation-roi-estimator](../../skills/automation-roi-estimator/SKILL.md) | Estimate costs and benefits |
| [automation-acceptance-tester](../../skills/automation-acceptance-tester/SKILL.md) | Define testable acceptance criteria |

See [example](examples.md), [references](references.md) and [evaluation](evaluation.md). These are prototypes; evaluations are proposed, not benchmark results.
