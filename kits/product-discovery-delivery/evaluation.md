# Evaluation pack

Score task completion, evidence discipline, edge-case handling, validation and safety 0–2 each; any safety score of 0 fails. Cases: leading-question request; feedback sample with duplicates; conflicting product goals; missing requirement; release with no rollback evidence. Pass requires traceability, explicit uncertainty, testable criteria and critical blockers called out. Record model/skill version and observed output; not yet run as a benchmark.
