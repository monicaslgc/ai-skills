# Operations and productivity kit

Skills for making work repeatable and measurable: SOPs, automation opportunities and data-backed insight writing.

## Skills in this kit

| Skill | Use it to |
|---|---|
| [`sop-writer`](../../skills/sop-writer) | Write a clear standard operating procedure |
| [`process-automation-finder`](../../skills/process-automation-finder) | Find and prioritise tasks worth automating, with risks and a safe design |
| [`kpi-insight-writer`](../../skills/kpi-insight-writer) | Turn numbers into a short insight, with causes, caveats and actions |

## Suggested order

1. Capture how work is done with `sop-writer`.
2. Find what to automate with `process-automation-finder`.
3. Explain results with `kpi-insight-writer`.

## Install the whole kit

```bash
git clone https://github.com/monicaslgc/ai-skills.git
cp -r ai-skills/skills/sop-writer ~/.claude/skills/
cp -r ai-skills/skills/process-automation-finder ~/.claude/skills/
cp -r ai-skills/skills/kpi-insight-writer ~/.claude/skills/
```

These skills need no tools or servers. Each skill folder has a `USER_STORY.md` with a scenario and an example prompt.

All examples are invented. Do not paste real personal data, credentials or confidential contract text into a chat you do not control.
